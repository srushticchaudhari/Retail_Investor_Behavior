# Retail_Investor_Behavior
A Study on Retail Investor Behavior Amid Geopolitical Uncertainty and Macroeconomic  Movements.

Objective:
Examine how retail investors reallocate funds across Index Funds, Gold ETFs, and Other ETFs in response to currency depreciation, repo rate changes, and geopolitical events (2023–2025).

Dataset/Source:
Secondary monthly data (Jan 2023–Dec 2025) from AMFI (fund inflows), RBI (repo rate), NSE (exchange rates), UCDP, and CFR (geopolitical event timelines).

Methods:
- Correlation analysis (fund inflows vs. exchange rate & repo rate)
- Event-based trend analysis (Russia-Ukraine, Israel-Hamas, US-China tensions, tariff fears, etc.)
- Line charts and event-effect tables

Tools:
Microsoft Excel (correlation, data cleaning, charting)

 Key Findings
- Gold ETFs show a moderate positive correlation with rupee depreciation (+0.43) — reinforcing gold's role as a currency hedge
- Index Funds show near-zero correlation with exchange rates and repo rates — largely insensitive to these factors
- Repo rate cuts correlate negatively with Gold ETF inflows (-0.26), suggesting investors move away from safe-havens when policy eases
- Geopolitical escalations (war, tensions) trigger gradual, sustained shifts toward Gold ETFs and other volatile ETFs — not sudden panic
- Retail behavior is asset-class differentiated and adaptive, not uniformly risk-averse — investors simultaneously hedge (gold) and speculate (other ETFs/Silver)
- Findings show association, not causation (fund flows used as behavior proxy)

Limitation: Time-bound, ETF/index-fund data only (excludes physical gold & direct stock holdings); correlation-only methodology.
